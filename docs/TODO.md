## В РАБОТЕ СЕЙЧАС
### [СДЕЛАНО] Статусы инфраструктуры вместо "0 у.е./мин"
В таблице зданий у инфраструктуры (income=0, infrastructure:true) НЕ показывать
"+0 у.е./мин". Вместо этого статус:
- вертолётки (helipad) и стоянки ВС (stand_*): "Занята" / "Свободна"
- ВПП (runway_*): "Работает" / "Сломана" (Сломана требует механики поломки — пока нет)
- ангар (hangar): "Занят" / "Свободен"

### [СДЕЛАНО] Аккордеон зданий
Клик по строке таблицы зданий → под ней разворачивается панель (аккордеон)
с состоянием и действиями (апгрейд/аренда/снос), вместо модального окна.
Клик ещё раз — сворачивается. Сетка остаётся только для перестановки зданий.
Содержимое панели = существующий renderBuildingModal, встроенный в строку.


### [СДЕЛАНО] Лимиты построек
BUILD_LIMITS в gameData.js: helipad 5, runway_small 2, runway_full 3, runway_big 6,
tower 3, stand_small 10, stand_medium 20, stand_large 20, fuel_depot 3, терминалы A-F по 1.
Проверка в /api/build + показ N/лимит в меню стройки + блокировка кнопки.

### [СДЕЛАНО] Группировка таблицы зданий
Группы (только непустые, со счётчиком): Вертолётный перрон, Самолётный перрон
(с под-группами Малые/Средние/Большие стоянки), Терминалы (A-F), ВПП, Диспетчерская,
Ангары, Топливо. Администрация и офис — вне групп. Клик по группе → список зданий,
клик по зданию → его панель. Несколько групп И несколько зданий открыты одновременно.
Сетка остаётся.

## УЖЕ СДЕЛАНО (для контекста)
- Большой ребаланс экономики: комиссия 20% с пассажиров договорных бортов,
  инфраструктура без пассивного дохода (income 0, upkeep 2/мин), аренда исключает

- Скрытие пустых зданий (hidden флаг).
- Ребаланс лизинга (40/250/130) и износа (0.5%/рейс, ремонт %-от-цены).
- Мягкие стоянки (место занято только когда борт на земле).
- Время стоянки вертолёта 2 мин (HELI_STAND_MINUTES).
- Фикс минуса при прилёте: нет склада → не заправляем; снижен расход топлива;
  поднята плата за прилёт.
- Дизайн сетки: макс 4 колонки, скроллбары в цвет сайта.
- Фоновые видео/картинки на входном и игровом экранах + админ-загрузка.
